# API Documentation Generator Skill

## Directives
1. Analyze source code functions, endpoints, and input models.
2. Produce comprehensive markdown documentation and an OpenAPI 3.0 specification snippet for each endpoint.
3. Explicitly list:
   - HTTP Method & Path
   - Headers and Query Parameters
   - Request Body JSON Schema
   - Response Status Codes (200, 400, 401, 404, 500) with example payloads.

## Output Guidelines
- Maintain standard markdown formatting with section headers.
- Provide example `curl` commands for testing endpoints.
